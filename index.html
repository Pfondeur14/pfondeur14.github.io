Python and Django Projects

Book Search

This is a Python program that uses the Google Books API adding user input to search for book Titles. Results are printed on a PDF including the Title, Author, Category, Page Count, average rating and an Image of the Book cover, if the book is not found the program will let the user know the information is not available. Users will be able to continue searching for book titles until they decide to exit the program.

See Github Repo

Commerce Biding site

Using Django I created and Ebay like e-commerce auctions site that allows users to post auction listings, place bids and add/remove listings to a "watchlist" page, and add comments. The users can visit a page that displays all active listings or filter by category.

Social Network

Using Python, JavaScript, HTML and CSS I created a social network that allows users to make posts and like posts. Users have a profile page and can follow or unfollow other users. The site shows the number of follows and followers a profile has and the entire page uses pagination to keep things organized.
