Python and Django Projects

Book Search

This is a Python program that uses the Google Books API adding user input to search for book Titles. Results are printed on a PDF including the Title, Author, Category, Page Count, average rating and an Image of the Book cover, if the book is not found the program will let the user know the information is not available. Users will be able to continue searching for book titles until they decide to exit the program.
